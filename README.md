# VB

Le deuxième cerveau de Samir : notes reliées, agenda, vision board, cartes mentales, graphe en hexagones et objectifs.

**Ouvrir l'app : https://vbtwelve.github.io/vb/**

- S'installe comme une vraie app depuis Chrome ou Edge (menu, puis « Installer VB »), et sur téléphone.
- Fonctionne hors connexion.
- Se met à jour toute seule à chaque lancement.
- Les données restent sur l'appareil (rien n'est envoyé sur internet). Sauvegarde et restauration depuis les Réglages.
